# Security policy

This project is documentation-only and has no supported runtime release yet.

Report vulnerabilities privately using
[GitHub private vulnerability reporting](https://github.com/gotthboard/gotth-extension-markdown/security/advisories/new).
Do not disclose vulnerabilities in public issues, pull requests, discussions,
or Forgejo tickets. Never include live credentials or private user content in
a report.

Use [GitHub Issues](https://github.com/gotthboard/gotth-extension-markdown/issues)
only for non-security reports. Forgejo is the canonical source, not a reporting
endpoint.
